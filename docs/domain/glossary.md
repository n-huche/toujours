# Glossary

The ubiquitous language of Toujours. These names are used, in English, in every document and in the code.

| Term | Meaning |
|---|---|
| **Account** | A person identified by an e-mail address. Owns at most one page and at most one subscription. |
| **Owner** | The account that owns a page. |
| **Visitor** | Anyone viewing a public page. Needs no account. |
| **Page** | A personal web page telling a couple's story. Owned by exactly one account. Reached at `/s/<slug>`. |
| **Slug** | The unique name of a page in its URL. |
| **Section** | One of the four parts of a page: Home, Diary, Memories, Playlist. |
| **Item** | A unit of content inside a section: an **Entry** (Diary), a **Moment** (Memories) or a **Song** (Playlist). |
| **Folder** | An owner-named group of items inside a section. May contain one level of subfolders. |
| **Image** | A picture uploaded to a page. Counted against the images limit. |
| **Character** | One visible character of text on a page. Counted against the characters limit. |
| **Working copy** | The owner's current version of a page, autosaved while editing. Never visible to visitors. |
| **Published content** | The version of a page that visitors see. Replaced when the owner publishes. |
| **Publish** | The owner's explicit action that makes the working copy public. |
| **Plan** | The paid offer: R$ 5 / month, 150 images, 1,500,000 characters, one page. |
| **Subscription** | An account's paid relationship with a plan. |
| **Trial** | The 48-hour free period of an account's first page, without a subscription. |
| **Recovery window** | The 7 days during which an expired page is offline but can still be restored (except after a takedown). |
| **Takedown** | Operator action that expires a page for a terms violation. The owner cannot restore it. |
| **Usage** | The page's current count of images and characters. |
